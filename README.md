 PerfectPetClub – Data Engineering Project

 Project Overview
PerfectPetClub is a data engineering project focused on working with customer relationship management (CRM) data and customer churn information.

This project repository includes data files, ETL notebooks, dashboard files, and reporting outputs to support data processing and analysis.

 Project Contents

- PerfectPetClub.db – Database file.
- PerfectPetClub_Churn.parquet – Customer churn data file.
- PerfectPetClub_CRM_report.csv – CRM report.
- PerfectPetClub_Dashboard.html – Dashboard in HTML format.
- PerfectPetClub_Dashboard.ipynb – Dashboard Jupyter Notebook.
- PerfectPetClub_ETL.html – ETL output in HTML format.
- PerfectPetClub_ETL.ipynb – ETL Jupyter Notebook.
- PerfectPetClub_server_log.csv – Server log data.

Key Components

- Data storage and management.
- ETL workflow.
- Customer churn data.
- CRM reporting.
- Data dashboard and visualisation.

Technologies and Tools

- Jupyter Notebook
- Python (project implementation to be documented)
- SQLite
- Parquet
- CSV
- HTML
